## 内容の要約

青岛大学未来战队が3508モーター用の低コスト減速箱（减速箱）を開源。2025年シーズンの初次尝试から2026年シーズンの再設計・多次迭代を経て完成。

### 適用ロボット
- 轮腿歩兵（轮足ロボット）
- 全向轮隧道歩兵（オムニホイールトンネル歩兵）

### 轻型减速箱（軽量型）
| 項目 | 仕様 |
|------|------|
| コスト | 100元未満（約2000円未満） |
| 出力 | 約9000回転時+潤滑脂で平均18W |
| 強度 | 20kg全向轮歩兵の任意飛坡対応 |
| 実績 | 区域赛2台の隧道歩兵で累計20+試合、沈头螺丝 looseningのみ |
| 背隙 | やや大きい |
| 互換性 | hexroll製品と安装孔位一致（孔位位置高さ/厚みは非一致） |

### 重型减速箱（重量型）
| 項目 | 仕様 |
|------|------|
| コスト | 約200元 |
| 出力 | 約9000回転時+潤滑脂で平均20W |
| 強度 | 轮腿歩兵で200回以上飛坡+100回以上ジャンプ |
| 軸受 | 角接触+腕组双轴承 |

### 加工方法
- 齿圈: 線切割+45鋼淬火（推奨: 华泰不锈钢制品厂）
- 齿轮: 某宝3.5元成品双联齿（motor1979店舗）
- CNC件: 铨洲智造 gy2025

## Summary

厦門大学嘉庚学院TCR戦隊が、RM2026シーズン使用の**完全なレーダー局システム**を開源。地面視覚、無線電、ドローン対抗の3つのサブシステムから構成。本機TCPでデータ交換、単一AD9361+単一受信チャンネル+段階的切替方式を採用。実戦検証済みで、正常状態では**单场累積易傷時間最高2070+秒、平均2050+秒**を達成。

## Concrete facts

- チーム：厦門大学嘉庚学院 TCR戦隊
- システム構成：地面視覚 + 無線電 + ドローン対抗
- 通信：本機TCPで陣営・干渉等級・暗号・座標・試合情報を交換
- 反制同期：独立A7串口で反制計算プラットフォームに本局反制回数を同期
- ハードウェア：単一AD9361、単一受信チャンネル、分阶段切替
- 運行順序：「一级干渉波成功 → 二级干渉波成功 → 情報波」
- 情報波座標が主要データ源、地面視覚はフォールバック・フォールトトレランス

## Technical details

### 性能指標
| 項目 | 数値 |
|------|------|
| 正常状态单场累積易傷時間（最高） | 2070+ 秒 |
| 正常场次平均累積易傷時間 | 2050+ 秒 |
| 全国赛局均易傷時間 | 低い（非ソフトウェア問題による） |

### 全国赛性能低下の原因
- 運算平台断电
- 裁判串口線問題
- これらの非ソフトウェア問題で数局の易傷が0/極低

### システムアーキテクチャ
```
地面視覚 ←TCP→ 無線電
            ↓
      データ融合・送信
            ↓
      ドローン対抗（A7串口同期）
```

## 内容の要約

华北理工大学Horizon战队が、空中ロボット（ドローン）へのレーザー照射による反無人機追跡システムを完全開源。

### 開発タイムライン

- その後: 後輩がメンテナンス・最適化を継続
- 完整形態考核: 远距离での実戦的効果を確認

### 全体アーキテクチャ
**【カメラ撮像 → 検出モジュール → ピクセル偏差→角度指令 → 下位機 → 云台制御】**

### 制御理論

1. **状態定義**
   - 云台状態: x_k = [θ_p,k, θ_y,k, ω_p,k, ω_y,k]^T
   - 視覚測定: z_k = (u_k, v_k, valid_k, t_k)
   - カメラパラメータ: C = (f_x, f_y)

2. **誤差計算（画像誤差→視線角誤差）**
   - Δθ_y,k = s_y·arctan(e_u,k / f_x)
   - Δθ_p,k = s_p·arctan(e_v,k / f_y)

3. **P型絶対角度制御**
   - θ^{cmd} = θ + K_p·Δθ
   - 従来の速度閉ループではなく「角度参照生成器」

4. **ダンピング項**
   - 云台フィードバック角速度または画像差分による推定角速度

5. **速度フィードフォワード**
   - 一時フィルタ後、振幅制限

6. **目標喪失時の探索戦略**
   - **円形探索**: 固定半径・固定周波数で等速円周スキャン
   - **螺旋探索（アキメデスの螺旋）**: r(θ) = aθ、中心から外へ広がる
   - **往復螺旋探索**: 外へ拡張→中心に戻る→再拡張

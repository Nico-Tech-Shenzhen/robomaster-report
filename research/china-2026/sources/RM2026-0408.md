## Summary

遼寧科技大学COD戦隊による、RM2026シーズンの**哨兵ロボット全システム（ナビゲーション・意思決定・自瞄・下位機制御）の完全開源**。ROS2 Humble + Nav2 + BehaviorTree.CPP + MPPIコントローラーを採用した現代的なロボットソフトウェアスタックの実践例。他チームの開源（同済大学、深北莫ポーラベア、中南大学FYT等）を積極的に参考にしている。

## Technical details

### ナビゲーション（ROS2 Humble + Nav2）
- **Giteeリポジトリ**: https://gitee.com/codnavgation/cod_-rm2026_-navigation
- **建図**: SLAM Toolbox + small_pointlio（純LIO方式）
  - map→odom→baselinkのtfを提供
  - odom→baselink: small_pointlio（高頻度里程計）
  - map→odom: 静的に'0','0','0'を発布
- **ナビゲーション方式**: Navigate Through Poses（連続航路点通過）
  - 単一航路点方式では脱困に時間がかかりすぎる問題を回避
  - ロボットが航路点間で停止せず滑らかに移動
- **コントローラー**: MPPI Controller（Model Predictive Path Integral）
  - 障害物回避性能は一流
  - 調整のポイント：stdではなくtemperatureとgammaに注目
  - pathfollow/pathalignのweightは10を超えないように
  - GoalCriticのweightとthreshold_to_considerを上げることで速度向上
- **Goal Checker**: nav2_controller::PositionGoalChecker（角度朝向を考慮しない）
- **脱困プラグイン**: 深北莫ポーラベア戦隊の開源を直接使用
- **fake yaw**: ポーラベア24年開源を参考

### 制御・下位機
- **Giteeリポジトリ**: https://gitee.com/cod_-control/rmcod2026_-sentry/tree/dev/
- 整車質量（裁判系统除く）：約12.50Kg
- スーパーキャパシタ搭載（30%以下で自動オフ）
- **原地変速小陀螺**:
  - 低速小陀螺：スーパーキャパシタ充電
  - 高速小陀螺：自瞄による瞬殺リスク低減 + カルマン予測攪乱
  - 遠心力による不下弾・カ弾問題の緩和
- **熱量制御**（同済大学・中科技大学を参考）:
  - 残熱>100: 19発/秒
  - 100→40: 線形減速
  - 40→30: 残熱=回復熱
  - 最後に3発の冗長を確保
- **功率制御**: 西交リバプール大学のモデルを参考

### 意思決定（BehaviorTree.CPP 4.8 + behavior.ros2）
- **Giteeリポジトリ**: https://gitee.com/codnavgation/cod_-rm2026_-behavior-tree
- Groot2によるリアルタイム検出機能を使用してデバッグ
- 状態機決策木パッケージ

### 自瞄
- **Giteeリポジトリ**: https://gitee.com/ustl-cod/sentry-auto-aim/tree/tmp/
- ベース：中南大学FYT戦隊の開源
- 参考：同済大学SuperPower戦隊25年開源
- **sp_vision_25の最適化**:
  - 高速回転目標（小陀螺）対応：装甲板を「迎面」・「离开」2段階に分離
  - shooting_angle非対称：迎面側55°幅、离开側20°幅
  - Lock機構：角度が近い装甲板間の反復切替によるジンバルブレ防止
- **Yaw角最適化**: 2段階探索でG2Oグラフ最適化を置換
  - 同済大学solver.cppを参考：云台yaw中心±70°で最適yawを探索

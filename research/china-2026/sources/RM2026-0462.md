## 内容の要約

天津大学北洋机甲战队の2024年シーズン自瞄（自動照準）フレームワーク「TJURM-2024」。OpenRM-2024ライブラリをベースにしたマルチパイプライン構成。

### アーキテクチャ

```
TJURM-2024
├── data/ (debug, speed, uniconfig, video)
├── include/
│   ├── data_manager/ (base.h, param.h)
│   ├── garage/ (garage.h, interface.h, wrapper_car/rune/tower.h)
│   └── threads/ (control.h, pipeline.h)
└── src/
    ├── data_manager/
    └── threads/
        ├── control/ (crc, receive/send_thread)
        └── pipeline/
            ├── baseline/ (主流水線: yolo矩形)
            │   ├── preprocessor_thread (NN前処理)
            │   ├── detector_thread (同期推論+NMS)
            │   └── tracker/ (pointer, locater, updater)
            ├── fourpoints/ (四点流水線)
            └── rune/ (打符流水線)
```

### 特徴
- **マルチパイプライン**: baseline（標準yolo矩形）/ fourpoints（四点ネットワーク）/ rune（打符）
- **ガレージ管理**: 車種別ラッパー（標準装甲板車、打符、前哨基地）
- **パラメータ管理**: JSONベース統一設定
- **内録機能**: 試合中の映像記録
- **デバッグ**: 逐フレーム画像保存

### 実行
```bash
cd TJURM-2024
sudo ./run.sh        # 通常実行
sudo ./run.sh -s     # imshow有効
sudo ./run.sh -c     # システムパラメータ強制上書き
```

### 自動起動
`rc.local` を使用した自動起動設定

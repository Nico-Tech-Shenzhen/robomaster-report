# RoboMaster 2026: セントリーロボットとレーダーシステム

## セントリーロボット

### 東北大学 TDT（優勝チーム）

- **四軸ジンバル越トンネルセントリーロボット** [RM2026-0101]
- 隊長張栄凱（3年生）：「今回、赛场上で目立ったのはセントリーロボット。搭載された智能アルゴリズム、決定・定位・导航がすべて素晴らしい」[RM2026-0102]
- **産業応用**: 低く狭い空間巡検ロボットへ転換可能（飛行機腹部、高速鉄道車両下部、地下管廊、橋梁箱梁、データセンター架空層）

### 華東理工大学 起源（3位チーム）

- **双輪足ロボット構造設計と制御** [RM2026-0105]
- **定位导航と自主決定アルゴリズム**
- **機械視覚と全方向感知**
- 上海站：「四台の輪脚戦車が如履平地、两台の自動セントリーがミッドフィールドで対垒」
- 上海交通大学交龍（全国4回王者）に2:1で勝利

### 遼寧科技大学 COD（全システム開源）

- **ROS2 Humble + Nav2 + BehaviorTree.CPP + MPPI**の完全開源 [RM2026-0408]
- セントリー質量：約12.50Kg（裁判系统除く）
- スーパーキャパシタ搭載（30%以下で自動オフ）
- **原地変速小陀螺**: 低速（充電）/高速（自瞄対策）
- **熱量制御**: 同済大学・中科技大学を参考に線形減速戦略
- ナビゲーション：SLAM Toolbox + small_pointlio + Navigate Through Poses
- シミュレーション：loopback sim（Gazebo不要）

### 深北莫 ポーラベア（Sim2Real開源）

- **Sim2Real開発フロー**の確立 [RM2026-0305]
- Gazeboシミュレーター + 実車検証
- ROS2 TFフレームワークの整車モデリング
- 自瞄とナビゲーションの座標系統合
- BehaviorTree.CPPベースの決策
- pre-commit + GitHub ActionによるCI/CD
- GitHub: 32リポジトリ以上（Apache-2.0）

### 浙江大学 Hello World（轮腿哨兵ナビゲーション開源）
- **2026年シーズン轮腿哨兵のナビゲーションアルゴリズム**を開源 [RM2026-0423]
- GitHub: https://github.com/Polyacetone/HWSentryNav26
- 轮腿構造の哨兵は地形適応性が高いがナビゲーションが複雑
- 深北莫PolarBearのSim2Realナビゲーションと比較可能

### 深圳大学 RobotPilots（Odin1空間記憶モジュール）
- **留形科技Odin1 SLAMモジュール**を哨兵の主感知ユニットとして導入 [RM2026-0419]
- 高頻度リアルタイム姿勢出力・安定したSLAM点群
- 競技場での2つの課題を特定: **光学窓保護**と**データ融合**
- 商用SLAMモジュールの競技場実戦運用の貴重な記録

### 中国石油大学（華東）RPS（東部赛区チャンピオン）

- 隊長王志明：「セントリーロボットはレーダーと視覚融合のAI自主決定システムを搭載。リアルタイムで敵目標を識別し、ミリ秒級の智能応答を実現」[RM2026-0104]
- **技術原理は無人運転技術と相通じる**

### 江南大学 SHARK（融合識別開源）

### 西北工业大学 WMJ（単SDR方案レーダー開源）
- **GNU Radio + 単SDR**で局均186.4s反制を達成 [RM2026-0411]
- GitHub: https://github.com/zplszz/WMJRadar
- 南理工Combat・華南師範PIONEERの開源をベースにGNU Radioチェーンを構築
- 1ヶ月でゼロから全機能構築
- 10秒三級干渉波下で約80組の情報波を解析
- **開源エコシステムの実証**: 他チームの開源が直接的にWMJの成功に貢献

### 香港浸会大学 Navigator Beta（RF開発記録）

- **PlutoSDR**を中心としたレーダーRFフロントエンド開発 [RM2026-0201]
- 外部プリセレクトフィルター：**B39431B3710U410** + QPL9547（25dBゲイン）
- **AD936xの注意点**: TXチャンネルのLOリーク問題
- V1.4.0ルールでの帯域外干渉対策
- 高分解能外差/超外差受信機の自研を推奨
- アンテナ評価：付属アンテナは433MHzで不整合の可能性

### 同済大学 SuperPower（アルゴリズムフレームワーク）

- **レーダー辅助吊射**機能を開発 [RM2026-0409参考文献]
- **ROS2ベースの視覚アルゴリズムフレームワーク**
- 傘库（umbrella library）形式のモジュール設計
- 「最小自瞄单元」構造（串口-DM_IMU-カメラ）
- auto_base機能包：基地誘導灯識別（飛ダーツ誘導用）

### 深圳大学 RobotPilots（自瞄フレームワーク開源）

- **RP-26AutoAim-Frame**をGitHubで開源 [RM2026-0409参考文献]

### 仲恺農業工程学院 奇点（自瞄開源）

## ナビゲーション技術スタック比較

| チーム | フレームワーク | SLAM | コントローラー | 決定 |
|--------|--------------|------|-------------|------|
| COD | ROS2 Humble + Nav2 | SLAM Toolbox + small_pointlio | MPPI | BehaviorTree.CPP |
| PolarBear | ROS2 + Nav2 | fast_lio / point_lio | PID追従 | BehaviorTree.CPP |
| 起源 | 独自（輪脚対応） | 不詳 | 不詳 | 状態機 |
| TDT | 独自（高評価） | 不詳 | 不詳 | AI自主決定 |

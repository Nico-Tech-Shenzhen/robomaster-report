# Editorial rules

1. Reader-facing prose is natural modern Japanese. Use Japanese new-character forms; never create vocabulary by mechanical Chinese character conversion.
2. `dic.md` is the naming authority. Preserve Simplified or Traditional Chinese exactly only in titles, quotations, source-form fields, and intentional first-use annotations.
3. Current claims require 2025–2026 evidence; prefer the current rule version and primary official, university, team, BBS, or repository source.
4. Separate documented fact, observed context, and report analysis. Analysis is allowed when labelled by wording and evidence; do not attribute it to an organizer.
5. Do not infer causality from affiliation or technical similarity. Distinguish documented transfer, participant/alumnus connection, recruitment/sponsorship, and similar technology.
6. Every number needs a definition, date, population, and direct supporting source. Repeated metrics must use the same definition or explain the difference.
7. Give each substantial topic one canonical section and link to it elsewhere. After structural edits, check navigation, headings, and internal links repository-wide.
8. For current technology use: team → 2026 system → problem → implementation → evidenced result. Generic ROS 2, AI, LiDAR, or PBL filler is not acceptable.
9. Link directly to the cited document, post, repository, or file. Record publication/update date and version where available; state access or evidence gaps.
10. Before completion run Japanese lint, link/number/heading/staleness validators, `git diff --check`, strict MkDocs build, and PDF build; then read chapters in order.

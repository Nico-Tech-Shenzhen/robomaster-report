    第3章　2026年のロボット技術スタック——チームから見た実装¶

    調査主体: 次世代ロボットエンジニア支援機構 Scramble（一般社団法人） 調査目的: 2026年シーズンの具体的な技術実装を、チーム→システム→問題→実装→成果の構造で記録する

    3.1 技術スタックの全体像¶

    2026年シーズンのRoboMasterコミュニティでは、以下の技術スタックが事実上の標準として確立している。これらは第4章で詳述するオープンソースフレームワークと、本章で述べる各チームの独自実装の組み合わせによって構成される。

    技術領域 事実上の標準 標準化の要因
    ミドルウェア ROS2 Humble/Jazzy RMOSSの採用とコミュニティ全体の追随
    視覚認識 YOLOv5/v8 + TensorRT + OpenCV rm_visionベースコードの普及
    LiDAR Livox Mid-70 / HAP / MID360 コストパフォーマンスとROS2ドライバーの充実
    シミュレーション Gazebo Fortress/Harmonic RMOSSのrmoss_gazebo採用
    カメラ 海康威視（Hikvision）工業カメラ、MindVision USB3.0 rm_vision/RMOSSでドライバーが標準化
    コード管理 GitHub（国際）+ Gitee（国内） オープンソース審査のGitHub必須要件と国内アクセス制限

    本章では、この標準スタックの上に各チームがどのような独自実装を施したかを、具体的な例を挙げて記述する。

    3.2 視覚認識システム——自動照準の進化¶

    3.2.1 装甲板識別の技術世代¶

    自動照準は、敵機の装甲板を認識し、0.1秒以内に照準を合わせることを目標とする。技術的進化は以下の通り：

    世代 時期 手法 処理時間（推定）
    第1世代 2015–2018 OpenCV伝統的手法（色閾値→輪郭検出→装甲板判定） 10〜30ms
    第2世代 2019–2022 YOLOv3/v5 + 従来手法のハイブリッド 5〜15ms
    第3世代 2023–2024 YOLOv5/v8 + TensorRT 3〜10ms
    第4世代 2025–現在 YOLOv8/v11 + TensorRT + ByteTrack 2〜8ms

    従来手法（OpenCV）の流れ[1]： 1. 輝度処理で画像輝度を調整 2. チャンネル差分で装甲板候補を抽出 3. 二値化＋膨張で輪郭強調 4. 回転外接矩形を取得 5. 灯条マッチングで同種灯条をペアリング 6. 長寛比・面積比で最終判定

    深層学習手法の流れ[2]： 1. YOLOv8m検出：カメラ画像からロボット・装甲板を同時検出 2. CUDA前後処理：GPU上で画像前処理・後処理を実行 3. TensorRT推論：最適化されたニューラルネットワークで高速推論 4. 拡張カルマンフィルタ追跡：装甲板の動きを予測し、弾道遅延を補正 5. PnP姿勢推定：装甲板の3次元位置・姿勢を算出 6. 弾道計算：重力・空気抵抗を考慮した仰角・方位角を算出

    3.2.2 rm_visionエコシステム¶

    rm_visionは、華南师范大学PIONEER戦隊の陳君（Chen Jun）によって開発された視覚フレームワークである[3]。MITライセンスで公開されており、以下のモジュール群を含む：

    • rm_auto_aim：装甲板自動照準アルゴリズム
    • ros2_mindvision_camera：MindVisionカメラドライバー
    • ros2_hik_camera：海康威視カメラドライバー
    • rm_serial_driver：視覚システムと電装制御のシリアル通信
    • rm_vision_simulator：視覚アルゴリズムシミュレーター

    rm_visionはDockerによるワンコマンド展開、Foxgloveによる可視化、LifeCycleノード管理など、現代的なROS2開発ワークフローを取り入れている。2024年シーズン以降、以下のチームがrm_visionをベースに改良・拡張している：

    フォーク 開発者 追加機能
    FaterYU/rm_vision 鄭宇（Zheng Yu） エネルギー機関（buff）モジュール、自動録画機能[4]
    RoboMaster-DLMU-CONE/rm_vision_2 大連海事大学 多タスク切替、複数目標間切替、激光測距センサ連携[5]
    SMBU-PolarBear-Robotics-Team/pb2025_rm_vision PolarBear戦隊 RMOSSメンテナの所属チーム自身もrm_visionを採用[6]

    RMOSSのメンテナである深セン北理莫斯科大学PolarBear Robotics Team自身が、2025年シーズンの視覚システムにrm_visionを採用した点は、RMOSSがミドルウェア・シミュレーション基盤として、rm_visionが視覚認識フロントエンドとして、両者が競合関係ではなく補完関係にあることを示している。

    3.2.3 エネルギー機関識別¶

    エネルギー機関（ルール上の回転標的）は、回転する扇風機状のパネルから構成される。2023年、哈工大CRT（HITCRT）チームの実装は以下の性能を達成した[7]：

    指標 数値
    処理時間 4ms/フレーム（Intel NUC 10、1280×1024）
    識別精度 近100%
    最大予測誤差 0.20rad
    平均予測誤差 0.06rad
    実戦成績 最高44環（2023年全国大会記録）

    この高性能は、低露光条件下での灯条検出と、角度の多項式フィッティングによる回転予測の組み合わせによって実現された。

    3.3 レーダーシステム——戦場の「脳」¶

    レーダーは全戦場の敵機位置を把握し、マーク進行度に応じて味方に攻撃増幅を付与する戦術的システムである。

    3.3.1 ハードウェア構成¶

    2024–2026年シーズンでは、以下の構成が事実上の標準となった[8]：

    センサー 採用モデル 理由
    LiDAR Livox Mid-70 / HAP / MID360 コストパフォーマンスとROS2ドライバーの充実
    カメラ 海康威視工業カメラ 国内調達が容易、ドライバーが整備済み
    GPU NVIDIA RTX 3060Ti / RTX 4090 点群＋画像の融合推論に必要な演算能力

    3.3.2 チーム実装例¶

    東北大学T-DT：レーダー融合システム。2023年レーダーMVP受賞。GitHubで公開されている[9]。

    華中科技大学狼牙：レーダーステーション。Livox Mid-70＋海康威視カメラ。全国大会版はRTX 4090で60Hz動作[8]。

    哈工大（深圳）南工骁鷹：ROS2 Humble対応レーダー。Livox HAP/Mid-70、海康カメラ、点群配准・クラスタリング・ニューラル推論を統合[8]。

    華北理工大学Horizon：LiDAR点群＋工業カメラ視覚融合レーダー。YOLOv5＋TensorRT、ByteTrack追跡を採用[8]。

    哈工大CRTチームのオープンソース実装は、以下の技術スタックを採用している[2]：

    コンポーネント 技術 性能
    検出ネットワーク YOLOv8m ロボット＋装甲板の同時検出
    推論加速 TensorRT 8.6 + CUDA 12.3 GTX 1650で32ms、RTX 3060Tiで11ms
    点群処理 LiDAR点群＋カメラ画像融合 3次元位置推定
    追跡 位置フィルタ＋多フレーム追跡 誤検出・位置跳変の抑制

    公式データでは、このレーダーシステムの平均マーク精度83.66%、最高93.55%を記録している[2]。

    3.4 ソフトウェアスタック——RMOSSとROS2¶

    3.4.1 RMOSSアーキテクチャ¶

    RMOSS（RoboMaster Open Source Software）は、深セン北理莫斯科大学PolarBear Robotics Teamの葛振鵬（Zhenpeng Ge）を中心にGitHub上で公開されたROS2ベースモジュール群である[10]。

    rmoss_core — 基盤機能モジュール：

    パッケージ 機能
    rmoss_util デバッグ、画像処理、ROS共通ラッパーツール
    rmoss_interfaces ROS2 msg/srv/action定義ファイル
    rmoss_base SBC（単板計算機）とMCU（組み込みマイコン）間の通信ツール
    rmoss_cam USBカメラ、仮想カメラのROSラッパー
    rmoss_projectile_motion 弾道逆運動学。目標位置から雲台仰角を計算

    rmoss_contrib — タスク級機能モジュール：

    パッケージ 機能
    rmoss_auto_aim 装甲板自動照準の基礎実装
    rmoss_power_rune2019 エネルギー機関識別の基礎実装

    rmoss_gazebo — シミュレーション：

    パッケージ 機能
    rmoss_gz_resources 標準ロボットモデル・フィールドモデル（SDF）
    rmoss_gz_base Gazebo-ROS通信ブリッジ。仮想下位機として動作

    RMOSSはApache 2.0ライセンスで公開されており、商用利用・改変・再配布をすべて許容している。

    3.4.2 シミュレーションとSim2Real¶

    PolarBearチームは、Gazebo Sim 8（Harmonic）対応のシミュレーションモジュールを開発した[11]。以下の機能を提供する：

    機能 内容
    フィールド再現 RMUL 2024/2025、RMUC 2024/2025の公式フィールド
    ロボットモデル 標準ロボットのSDFモデル、裁判システムモデル
    仮想下位機 rmoss_gz_baseが実際のMCUと同等のインターフェースを提供
    通信ブリッジ ros_gz_bridgeでROS2とGazebo間を連携
    Web操作 操作手端末・裁判システム端末をブラウザで実装

    PolarBearチームは2025年シーズン、Sim2Realによるナビゲーション開発を報告した[12]。Gazebo上でナビゲーションアルゴリズムを検証後、ほぼ同じROS2コードを実機に移植している。ただし、視覚アルゴリズムについてはSim2Realの壁が存在する。Gazeboは発光物体（装甲板）の写実的レンダリングができないため、視覚系は実機での検証が必須となっている[12]。

    3.5 ハードウェアプラットフォーム¶

    3.5.1 制御系——STM32とDJI裁判システム¶

    RoboMasterロボットの制御系は、主にSTM32マイコンを中核とする。

    機能 典型チップ/製品 備考
    メインコントローラ STM32G4 / STM32F4 Cortex-M4/M7、浮動小数点演算
    モーター駆動 Amulet_controller / DJI C620 ブラシレスモーター用ESC
    CAN通信 TJA1050 ロボット内モジュール間通信
    裁判システム DJI Referee System 装甲板ヒット検出、HP管理、通信

    DJI裁判システムは、各ロボットの装甲板に埋め込まれたセンサーで弾丸衝突を検出し、17mm弾丸は50ms間隔、42mm弾丸は200ms間隔でダメージを結算する[3]。

    3.5.2 センサー——産業用カメラとLiDAR¶

    センサータイプ 代表製品 用途
    産業用カメラ 海康威視 MV-CA series 装甲板識別のメインカメラ
    MindVision 低遅延、高フレームレート
    深度カメラ Intel RealSense D435 距離計測（一部チーム）
    LiDAR Livox Mid-70 / HAP / MID360 レーダー用3次元環境認識

    3.5.3 推論加速——JetsonからRTXまで¶

    プラットフォーム 典型製品 用途 推論時間（YOLOv8m）
    エッジAI NVIDIA Jetson Orin NX 歩兵・哨兵の車載推論 15〜30ms
    ノートPC級 NVIDIA GeForce GTX 1650 レーダー・予算制限チーム 32ms[2]
    デスクトップ級 NVIDIA GeForce RTX 3060Ti レーダー・トップチーム 11ms[2]
    ハイエンド NVIDIA GeForce RTX 4090 レーダー・高性能要求 5ms未満

    3.6 2026年シーズンの技術的到達点¶

    3.6.1 区域大会の創出成果¶

    2026年シーズンの区域大会統計によると、参加チームは特許150件超、論文近70篇、その他の創新成果50件超を産出した[13][14]。その中には、双七軸倣人機械アーム、VRヘッドセット操作などの革新的技術方案が含まれる。

    3.6.2 技術水準の年次向上¶

    参加者の技術水準は、毎年のルール変更とオープンソースの蓄積によって加速的に向上している。

    年次 標準的な技術 トップチームの技術
    2017 OpenCV灯条検出、手動照準 単純な自動照準
    2019 YOLOv3導入、深層学習の普及 エネルギー機関自動撃破
    2021 TensorRT高速化、多機協調 SLAM＋視覚融合
    2023 ROS2移行、RMOSS標準化 レーダー＋自動戦術決定
    2025 YOLOv8/v11、ByteTrack追跡 Sim2Realナビゲーション
    2026 無線充電統合、大規模チーム運用 車輪脚エンジニア、双七軸アーム

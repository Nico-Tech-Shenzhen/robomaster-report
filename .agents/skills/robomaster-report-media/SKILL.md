# Evidence-led media

Read the target entry in `REPORT_PLAN.md` and, when present, `MEDIA_PLAN.md`. Add media only when it explains a mechanism, documents field evidence, or makes a comparison easier to verify.

For every item record: stable media ID; target chapter/section; creator or source institution; original URL or local asset path; capture/publication date; copyright or license status; permitted use; caption; claim citation; and web/PDF treatment.

- Author field photographs: retain original filename and metadata; identify photographer/owner and consent or publication basis.
- Bilibili: provide an embed where supported plus a normal fallback link, uploader/title, access date, and `HH:MM:SS` or `MM:SS` timestamp for the cited sequence.
- External images: verify license or obtain permission; a citation alone does not grant reuse.
- Original diagrams: label them as report-created and cite the data/evidence from which they were derived.
- Tables: cite cells or rows when sources differ and design for narrow web and paginated PDF layouts.
- Captions: state what the reader should observe, then attribution/source. Do not claim more than the cited evidence shows.

Verify links, local asset references, captions, and both web and PDF output where applicable. Do not create decorative media galleries.

# 第7章　大学・制度・他競技との違い

## 7.1 大会名称と主催体制

中国語の「全国大学生机器人大赛」は、日本語では「全国大学生ロボット大会」とする。RoboMasterは時期によって同大会の枠組み、共青団中央、全国学連、地方政府、DJIとの表記が変化している。現在のページに過去の主催者名が残る場合もあるため、制度を記述するときは必ず当該年の通知を使う。

## 7.2 ホワイトリスト

中国高等教育学会が公表する「全国普通高校大学生競技リスト（全国普通高校大学生竞赛榜单）」は、大学が競技実績を扱う際の参照枠で、通称ホワイトリストと呼ばれる。掲載・非掲載の年次変化は事実として確認できるが、その理由を「自立したから外れた」「政府が支援を止めた」と説明する公式根拠は確認できない。

制度変化は次の三層で書き分ける。

- **事実**：当該年のリスト、主催通知、大学の単位・表彰規程に何が記載されたか。
- **周辺状況**：参加規模、DJIの運営、大学内支援が同時期にどう変化したか。
- **分析**：掲載が予算、単位、教員評価に影響し得るが、大学ごとの差を調査する必要がある。

全国一律の因果を置かず、大学ごとに競技費、工房、単位、指導教員の業績評価を確認する。

## 7.3 大学教育との接続

RoboMaster活動が正規授業、卒業設計、課外活動、研究室プロジェクトのどこに置かれるかは大学で異なる。江蘇大学などには教育改革課題として扱う資料がある一方、すべての参加大学が単位を付与する証拠はない。大学が提供できる資源は、教員顧問、工房、安全管理、資金、単位、成果表彰、調達事務である。競技成績だけを評価すると文書・安全・後継者育成が弱くなるため、技術報告や引継ぎを学修成果へ含める設計が望ましい。

## 7.4 比較は機構を明らかにするために行う

| 競技 | RoboMasterとの有用な比較点 | 単純比較できない点 |
|---|---|---|
| ABU ROBOCON | 大学単位の年次課題、機械・制御統合 | 主に一課題の達成で、兵種群の継続運用とは異なる |
| RoboCup | 自律性、研究コード、論文との接続 | リーグが多様で、単一の運営・ハードウェア条件ではない |
| FRC | 年次ルール、地域チーム、企業メンター、部品供給 | 高校生中心で、大学研究室との制度関係が異なる |
| Eurobot | 年次テーマ、小規模チーム、自律機 | 規模と対戦・裁判システムが異なる |
| BattleBots | 高負荷機械、安全、興行性 | 教育課程、公開規範、自律性を主目的としない |

RoboMasterの特徴は「最も高度」という順位ではない。複数兵種、射撃・資源・情報の対戦、統一裁判システム、シーズン中の技術検査、大学チームの複数年継承、BBSを介した公開、企業の採用が同じ運営面に接続されている点にある。他競技にも各要素は存在するが、この組合せと比重が違う。

## 7.5 国際展開を語る際の注意

リーグ戦や北米チームの参加例から「世界規模」を述べる場合、登録国数、実出場チーム、オンライン参加、大学数を分ける。五大湖連合大学の2026年ヒーロー公開は国際チームの具体例だが、それ一件で各地域に同等の部品供給・大会密度があるとは言えない。国際比較では、旅費、無線・発射物規制、部品輸入、安全基準、大学暦が移植条件になる。

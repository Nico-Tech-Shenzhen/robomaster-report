# 第9章　他の競技とは何が違うか——国際比較

> **調査主体**: 次世代ロボットエンジニア支援機構 Scramble（一般社団法人）
> **調査目的**: RoboMasterの独自性を、他の主要ロボット競技との比較を通じて明確にする

---

## 9.1 比較の枠組み

RoboMasterを他の競技と比較する際、単なる「競技A vs 競技B」の表ではなく、以下の分析軸に沿って比較する。

| 分析軸 | 問い |
|:---|:---|
| 年次ルール進化 | 競技は毎年ルールを変更し、前年の最適解を無力化するか |
| 工学の範囲 | 競技が要求する技術領域の広さ |
| 自律性 | ロボットの自律的な判断・行動がどこまで求められるか |
| チーム規模 | 1チームあたりの人数と組織の複雑さ |
| オープンソース | 技術共有が制度として定着しているか |
| 大学統合 | 大学の正規カリキュラムや単位認定と連携しているか |
| スポンサー構造 | 資金源の多様性と企業の関与の深さ |
| 人材パイプライン | 競技経験が産業界の採用に直結しているか |
| 知識蓄積 | 過去の技術が次年度に継承される仕組みがあるか |

本章では、各競技をこれらの軸に沿って分析する。

---

## 9.2 ABU RoboCon

### 9.2.1 概要

ABU RoboCon（Asia-Pacific Broadcasting Union Robot Contest）は、1988年にNHKが創設した国際的な大学ロボット競技大会である。日本では「ロボコン」として広く知られている。各国の国内大会で優勝したチームが、年度ごとに変わる開催国で国際大会に出場する形式である。

### 9.2.2 RoboMasterとの比較

| 分析軸 | RoboMaster | ABU RoboCon |
|:---|:---|:---|
| 年次ルール進化 | 毎年ルール変更。前年の優勝戦術を無力化 | 毎年ルール変更だが、テーマが大きく変わる（投げ合い・乗り合い等） |
| 工学の範囲 | 7種類のロボット・リアルタイム対抗・自動照準・レーダー | 2台のロボット協調・特定の課題達成 |
| 自律性 | 哨兵は完全自動。他は遠隔操作＋自動照準 | 基本的に自律走行が中心だが、戦術的な判断は限定的 |
| チーム規模 | 20〜100名以上 | 10〜30名程度 |
| オープンソース | オープンソース審査制度（2025年～）。GitHub公開義務 | 個別チームの裁量。全国規模の統一的な共有基盤はない |
| 大学統合 | 一部大学で正規カリキュラム化 | 日本では課外活動が主流 |
| スポンサー構造 | DJI主導＋複数企業スポンサー | NHK・企業スポンサー（国により異なる） |
| 人材パイプライン | DJI等が専用採用チャネルを設置 | 企業連携はあるが、制度化されたパイプラインは限定的 |
| 知識蓄積 | RMOSS・rm_vision・BBS技術報告書 | チーム単位の継承が主流。標準化された共有基盤はない |

**重要な相違点**：RoboMasterは「7対7のリアルタイム対抗戦」であり、戦術の多様性と技術の複雑さがRoboConを上回る。一方、RoboConは「国際的な国別対抗」という格式を持ち、参加国の多様性ではRoboMasterを上回る。

## 9.3 FIRST Robotics Competition（FRC）

### 9.3.1 概要

FRC（FIRST Robotics Competition）は、1989年にアメリカで創設された高校生対象のロボット競技大会である。非営利団体FIRSTが運営し、ボランティア文化が根付いている。

### 9.3.2 RoboMasterとの比較

| 分析軸 | RoboMaster | FRC |
|:---|:---|:---|
| 年次ルール進化 | 毎年ルール変更 | 毎年テーマ変更（Deep Space・Rapid React等） |
| 工学の範囲 | 機械・電装・制御・視覚・戦術の統合 | 機械・電装・制御。視覚・AIは発展途上 |
| 自律性 | 哨兵自動＋自動照準 | 自動期間あり（15秒）だが、基本的には遠隔操作 |
| チーム規模 | 20〜100名以上 | 高校生中心。メンター（企業技術者）が必須 |
| オープンソース | GitHub公開義務。RMOSS等の標準基盤 | チームごとの裁量。標準化は進んでいない |
| 大学統合 | 大学生が主体。一部で正規科目化 | 高校生対象。大学連携は限定的 |
| スポンサー構造 | DJI主導＋企業スポンサー | 地域企業・ボランティア寄付が中心 |
| 人材パイプライン | 企業が専用採用チャネルを設置 | 企業連携はあるが、採用パイプラインとしての制度化は弱い |
| 知識蓄積 | RMOSS・BBS・オープンソース審査 | チーム単位の継承。標準ミドルウェアはない |

**重要な相違点**：FRCは「高校生対象」であり、メンターシップと教育的配慮が重視される。RoboMasterは「大学生対象」であり、企業の即戦力人材育成が強調される。FRCはボランティア文化と非営利モデルが特徴的だが、RoboMasterは企業主導の投資モデルが特徴的である。

## 9.4 BattleBots

### 9.4.1 概要

BattleBotsは、1999年からアメリカで開催されている格闘ロボット競技大会である。遠隔操作されたロボットが互いを破壊することを目的とし、エンターテインメント性が高い。

### 9.4.2 RoboMasterとの比較

| 分析軸 | RoboMaster | BattleBots |
|:---|:---|:---|
| 年次ルール進化 | 毎年ルール変更。技術進化を強制 | 基本的に同一ルール。ロボットの破壊力が焦点 |
| 工学の範囲 | 機械・電装・制御・視覚・戦術の統合 | 主に機械設計と耐久性 |
| 自律性 | 哨兵自動＋自動照準 | 完全遠隔操作。自律性は要求されない |
| チーム規模 | 20〜100名以上 | 個人〜小規模チーム（5〜15名） |
| オープンソース | GitHub公開義務。技術共有が制度化 | 個人のノウハウ。共有の制度化はない |
| 大学統合 | 大学生が主体 | 年齢制限なし。学生競技ではない |
| スポンサー構造 | DJI主導＋企業スポンサー | 個人スポンサー・クラウドファンディング |
| 人材パイプライン | 企業が専用採用チャネルを設置 | 産業パイプラインとしての機能は限定的 |
| 知識蓄積 | RMOSS・BBS・オープンソース審査 | 個人の経験に依存 |

**重要な相違点**：BattleBotsは「破壊」のエンターテインメントが核心であり、教育的目的や技術の蓄積は副次的である。RoboMasterは「製品開発プロセスの体験」と「技術の継承」が核心であり、競技はその手段である。

## 9.5 Eurobot

### 9.5.1 概要

Eurobotは、1998年にフランスで創設されたヨーロッパの大学・高校生対象ロボット競技大会である。自律型競技を基本とし、参加チームが独自のロボットを開発する。

### 9.5.2 RoboMasterとの比較

| 分析軸 | RoboMaster | Eurobot |
|:---|:---|:---|
| 年次ルール進化 | 毎年ルール変更 | 毎年テーマ変更 |
| 工学の範囲 | 機械・電装・制御・視覚・戦術の統合 | 機械・電装・制御。視覚は補助的 |
| 自律性 | 哨兵自動＋自動照準 | 完全自律が基本 |
| チーム規模 | 20〜100名以上 | 10〜20名程度 |
| オープンソース | GitHub公開義務。標準基盤あり | 個別チームの裁量 |
| 大学統合 | 一部で正規科目化 | フランスでは大学連携が強い |
| スポンサー構造 | DJI主導＋企業スポンサー | 大学予算・小規模スポンサー |
| 人材パイプライン | 企業が専用採用チャネルを設置 | 地域企業との連携はあるが制度化は弱い |
| 知識蓄積 | RMOSS・BBS・オープンソース審査 | チーム単位の継承 |

**重要な相違点**：Eurobotは「完全自律」を基本とする点でRoboMasterと異なる。RoboMasterは「遠隔操作＋自動照準＋哨兵自律」というハイブリッド形式であり、人間の戦術判断と機械の反射的速度を組み合わせている。

## 9.6 RoboCup

### 9.6.1 概要

RoboCupは、1997年に創設された国際的なロボットサッカー大会である。「2050年までに人間のサッカー世界チャンピオンに勝つロボットチームを作る」という長期ビジョンを掲げている。

### 9.6.2 RoboMasterとの比較

| 分析軸 | RoboMaster | RoboCup |
|:---|:---|:---|
| 年次ルール進化 | 毎年ルール変更 | 基本ルールは安定。詳細な調整のみ |
| 工学の範囲 | 機械・電装・制御・視覚・戦術の統合 | AI・自律制御・マルチエージェントが核心 |
| 自律性 | 哨兵自動＋自動照準 | 完全自律が基本（Small Size等を除く） |
| チーム規模 | 20〜100名以上 | 研究チーム（5〜20名） |
| オープンソース | GitHub公開義務。標準基盤あり | オープンソース文化は強いが、制度化はされていない |
| 大学統合 | 一部で正規科目化 | 研究プロジェクトとして大学に統合 |
| スポンサー構造 | DJI主導＋企業スポンサー | 大学予算・研究費が中心 |
| 人材パイプライン | 企業が専用採用チャネルを設置 | 研究者・大学院進学が主流 |
| 知識蓄積 | RMOSS・BBS・オープンソース審査 | 学術論文・オープンソースコード |

**重要な相違点**：RoboCupは「AI研究の実証場」としての側面が強く、学術的な成果物（論文）が重視される。RoboMasterは「製品開発の実践場」としての側面が強く、動くロボットと企業への就職が重視される。

---

## 9.7 RoboMasterの独自性——総合的な位置づけ

上記の比較から、RoboMasterの独自性は以下の点に集約される。

### 9.7.1 「競技＋産業＋教育」の三層構造

RoboMasterは単なる競技ではなく、以下の3つの層を同時に持つ。

1. **競技層**：7対7のリアルタイム対抗戦。エンターテインメント性と技術的難易度の両立
2. **産業層**：企業の採用パイプライン、スタートアップ創出、サプライチェーン育成
3. **教育層**：大学カリキュラム統合、PBL、年次ルール変更による継続的学習

他の競技は、通常これらの層のうち1〜2つに特化している。RoboMasterは3つを意図的に統合している点で独自である。

### 9.7.2 オープンソースの制度化

RMOSS・rm_vision・オープンソース審査制度・オープンソース賞という、技術共有を「義務＋報酬」で支える制度構造は、他のロボット競技には見られない。これにより「前年の最適解が今年のベースライン」という蓄積構造が形成されている。

### 9.7.3 企業主導の投資モデル

DJIが累計数億元規模を投じて競技を創設・運営し、自社の採用パイプラインとして機能させているモデルは、FRCの非営利モデルやRoboConのNHK主導モデルとは根本的に異なる。このモデルの持つ長所（持続的な資金投入、明確な産業連携）と短所（DJI依存リスク）を併せ持つ。

# 第1章　RoboMaster 2026の現場

## 1.1 まず、試合を一局見る

RoboMaster University Championship（RMUC）の試合では、赤・青の二チームが障害物と高低差のあるフィールドにロボット群を展開する。17 mmまたは42 mmの樹脂弾を撃つヒーローと歩兵、資源を扱うエンジニア、自律行動する哨兵、上空から介入する空中ロボット、固定目標を狙う飛鏢システム、敵機の位置を味方へ送るレーダーが、同じ裁判システムに接続される。弾丸が装甲モジュールへ命中すると耐久値が減り、発射熱量やシャーシ電力も機上と競技サーバーの双方で管理される。勝敗は射撃精度だけでなく、資源獲得、強化、索敵、経路選択、修理、操縦者間の情報共有を含むシステム戦で決まる。[2026年全国大会段階の競技規則V2.1.0](https://bbs.robomaster.com/wiki/20204847/811947)を基準にすると、区域大会と全国大会ではルール版が異なるため、本章は2026年8月17日時点の全国大会仕様を「現行」とする。

観客に見えるのは数分間の対戦だが、学生が作る対象は機体だけではない。機械加工品、プリント基板、組み込み制御、電源、無線通信、コンピュータビジョン、自己位置推定、経路計画、戦術画面、試験治具、運搬箱までが一つの成果物である。主催者が供給するモーター、裁判システム、画像伝送装置などを組み込みつつ、寸法、質量、レーザー安全、電池安全、装甲板の取付位置を制作仕様へ適合させなければ出場できない。[制作仕様V2.0.0（2026年6月26日）](https://bbs.robomaster.com/wiki/20204847/811947)は、全国大会前に空中ロボット、エンジニアの最大展開寸法、スーパーキャパシタ管理モジュールなどを更新した。競技成績以前に、変更を追跡して設計・文書・検査手順へ反映する構成管理が必要になる。

## 1.2 2026年の編成

| 要素 | 主な役割 | 学生が解く問題 |
|---|---|---|
| ヒーロー | 42 mm弾による遠距離または近接攻撃 | 高精度発射、反動、質量配分、機動性 |
| 歩兵 | 17 mm弾による機動戦 | 自動照準、追跡、熱量・電力管理 |
| エンジニア | 資源取得、エネルギーユニット装配、救援 | 多自由度マニピュレーター、遠隔操作、接触作業 |
| 哨兵 | 自律巡回、射撃、戦術行動 | 測位、地図、経路計画、意思決定、フェイルセーフ |
| 空中ロボット | 上空からの攻撃・支援 | 飛行安全、通信、限られた搭載量 |
| レーダー | 敵機検出と位置送信、対空反制 | LiDAR・カメラ融合、座標変換、識別、通信 |
| 飛鏢 | 基地への固定設備攻撃 | 発射再現性、照準、機構安全 |

この表は「標準キットを七台組み立てる」という意味ではない。例えば同じヒーローでも、2026年は近戦優先と遠距離優先で発射熱量上限が異なり、チームは戦術と機械構成を同時に選ぶ。同済大学SuperPowerは[中心供弾機構の設計資料](https://bbs.robomaster.com/article/1892264)で、車輪脚ヒーローの重心を中央へ寄せるため、一般的な接線供弾から配置を再検討した。競技規則のパラメーターが、部品の位置と制御可能性まで連鎖する例である。

## 1.3 大会は単一ではない

RoboMaster高校シリーズには、フル編成で戦うRMUC、参入しやすいリーグ戦（RMUL）、単体ロボットや特定能力を競う種目がある。2026年の重慶リーグ戦では、参加38チームのうち3対3対抗に32、歩兵対抗に21、エンジニア課題に10チームが登録した。[重慶大会参加手冊V2.0](https://bbs-web-static.robomaster.com/250bcff7b9fa40c39fe4d3dcf03b9c4d1773228470534/RoboMaster%202026%20%E6%9C%BA%E7%94%B2%E5%A4%A7%E5%B8%88%E9%AB%98%E6%A0%A1%E8%81%94%E7%9B%9B%EF%BC%88%E9%87%8D%E5%BA%86%E7%AB%99%EF%BC%89%E5%8F%82%E8%B5%9B%E6%89%8B%E5%86%8CV2.0.pdf)の内訳は、大学が最初から全兵種を揃えなくても段階的に参加できることを示す。

RMUC区域大会は2026年5月13日から6月2日に東部・南部・北部で実施された。主催者が公開した[区域大会データ](https://bbs.robomaster.com/article)を整理した公開索引では、96大学、266試合613局、約402万行の秒単位状態、約147万件のイベントが確認できる。これは全国大会結果を含まない区域大会の分析単位であり、「年間参加校数」や「RoboMaster全種目の参加校数」と混同しない。

## 1.4 2026年をどう読むか

2026年の全国大会は本稿基準日の時点で最終結果の公式公示を確認できていない。したがって本報告は、未確定の優勝校を予測せず、公開済みの規則、区域大会結果、検査通過名簿、チームの実機資料を扱う。たとえば中国石油大学（華東）のRPSは東部区域大会で優勝したが、これは全国優勝ではない。同校の大学記事は、試合後に操縦・戦術・機体不具合を即日で振り返ったことも記す。[区域大会報告](https://youth.upc.edu.cn/2026/0602/c11146a492315/page.psp)から読み取れるのは順位だけでなく、短い試合間隔で改善を回す運用である。

以降は、規則が設計課題をどう作るか（第2章）、実際の2026年機体（第3章）、設計資産が次年度へ残る仕組み（第4章）へ進む。歴史や産業論より先にこの順序を置くのは、RoboMasterの中心が、学生が規則に適合する複数ロボットを一シーズンで統合し、試合で運用する行為にあるためである。

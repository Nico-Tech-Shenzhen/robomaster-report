## 読み方と限界

- 「現行」は全国大会規則V2.1.0（2026年7月16日）を指す。区域大会はV1系で実施された。
- 2026年全国大会の最終結果は基準日時点で公式公示を確認できないため、未確定の順位は記載しない。
- チーム公開値は当該チームの報告として扱い、全チームへ一般化しない。
- 事実、周辺状況、本報告の分析を分け、所属関係や技術的類似から因果を推定しない。

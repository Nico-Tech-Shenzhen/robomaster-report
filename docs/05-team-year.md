# 第5章　一年でロボット群を作る組織

## 5.1 チームは小さな製造組織である

フル編成のRMUCチームには、機械、組み込み、電装・基板、アルゴリズム、操縦・戦術、運営が必要になる。学生数は大学と種目で大きく異なるため、「標準は100人」とは置かない。リーグ戦の少人数チームと、複数兵種を開発する全国大会チームは別の母集団である。共通するのは、専門別担当が一台ではなく機体群とフィールド設備を期限内に統合することだ。

## 5.2 シーズンの実務

| 時期の目安 | 主な仕事 | 残すべき成果物 |
|---|---|---|
| 9–10月 | 新入生募集、前年の振り返り、安全教育 | 募集要件、技能表、事故・故障一覧 |
| 10–12月 | 基礎課題、規則初版の分解、シーズン計画 | 教材、要求一覧、予算、マイルストーン |
| 1–3月 | 方式選定、詳細設計、基板・部品発注 | 設計審査記録、CAD、回路図、部品表 |
| 3–4月 | 完全形態、単体試験、統合 | 試験結果、ソフトウェア版、配線図 |
| 4–6月 | 検査準備、交流試合、区域大会 | 検査表、予備品表、試合ログ |
| 6–8月 | 全国大会向け改修、技術報告 | 変更管理、再試験、公開資料 |
| 8–9月 | 解体調査、引継ぎ | 失敗条件、翌年への未解決課題 |

日付は固定カリキュラムではない。2026年は4月1日に完全形態審査通過名簿、4月13日に区域大会参加名簿が公示され、5～6月に区域大会、6月末以降に全国段階の規則が発行された。[公式公告一覧](https://www.robomaster.com/zh-CN/resource/announcement/competition)を見ると、完成後も規則版と登録機体を追う必要がある。

## 5.3 新入生を戦力にする

募集人数より重要なのは、基礎課題から実機担当へ移る経路である。機械なら公差付き部品と組立図、組み込みならCANバス上のモーター制御と安全停止、アルゴリズムならカメラ較正と時刻同期、運営なら調達・会計・スポンサー文書を課題にする。採用試験だけで選別すると、担当者が卒業した領域が空洞化する。教材、レビュー担当、合格基準、再挑戦の手順までがオンボーディングである。

車輪脚を三年目に完成したと記すSPRの記事は、公開資料とチーム内支援の両方を明示する。短期講義で高度制御を習得した話ではなく、複数年にわたる担当経験が成果へ結び付いた例である。

## 5.4 設計審査と統合

設計審査では「動くか」だけでなく、要求への適合、質量・電力予算、重心、加工可能性、組立順、保守時間、故障時の安全、予備品を確認する。車輪脚なら制御担当だけでなく、減速機、フレーム、電源、装甲板、発射系の担当が同じ重心表を見る。エンジニアなら腕の到達範囲図、自己干渉、カメラ視野、最大展開寸法、操縦UIを一枚のシナリオで検証する。

統合試験は、単体合格の寄せ集めではない。カメラの露光変更が推論遅延を変え、CPU負荷が通信周期を乱し、発射振動がLiDAR外参をずらし、キャパシタ放電が電源ノイズを増やす。変更後に影響範囲を再試験する構成管理が不可欠である。

## 5.5 交流試合と技術検査

交流試合は勝敗の予行演習だけでなく、電波環境、衝突、長時間運転、操縦者連携を同時に試す負荷試験になる。試合後は、時刻を合わせた裁判システムログ、機上ログ、映像、操縦者メモから、再現条件と修正担当を決める。RPSの2026年区域大会報告にある毎回の振り返りは、この短周期ループの一例である。

検査は最後の儀式ではない。設計初期から検査治具と測定条件を再現し、規則改版ごとに差分を反映する。レーザー、電池、スーパーキャパシタ、最大寸法のような安全・境界条件は、試合性能と同じバックログで管理する。

## 5.6 予算、工房、スポンサー

費用は機体部品だけではない。加工工具、試験設備、会場輸送、宿泊、予備部品、破損、計算機、クラウドサービスが必要になる。大学の工房と技術職員、スポンサーの材料・加工支援、卒業生のレビューは資金以外の能力を補う。ただし、公開された一チームの予算を全国標準へ外挿できない。比較するときは、対象種目、機体数、現物協賛、設備費を分ける。

## 5.7 教育効果をどう測るか

「PBLだから成長する」という循環論法は避ける。観察可能なのは、学生が要求分解、方式選定、製造、統合、検査、運用、事後分析、引継ぎを反復し、レビュー可能な成果物を残すことだ。教育効果を評価するなら、参加人数より、設計判断の根拠、試験の再現性、後輩が変更できる文書、卒業後の進路を別々に測るべきである。

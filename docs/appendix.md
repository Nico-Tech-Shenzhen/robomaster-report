# 付録

## A. 用語集

本レポートで使用する主要な用語を以下に定義する。

| 用語 | 定義 |
|:---|:---|
| RoboMaster（機甲大師賽） | DJIが主催する大学ロボット競技大会。2009年発足以降、年次大会が開催されている |
| RMUC | RoboMaster University Championship。全国大会。7対7のリアルタイム対抗戦 |
| RMUL | RoboMaster University League。地域連盟大会 |
| ヒーロー | 主力攻撃ロボット。42mm弾丸を使用 |
| 歩兵 | 標準攻撃ロボット。17mm弾丸を使用 |
| エンジニア | 資源回収・前哨基地再建・ロボット修理を担当する非武装ロボット |
| 哨兵 | 完全自動運行の基地防衛ロボット |
| 飛鏢 | 遠距離高ダメージ攻撃システム |
| レーダー | 全戦場の敵機位置把握システム |
| オープンソース審査 | 2025年シーズンから導入された技術引用の透明化制度 |
| オープンソース賞 | 技術のオープンソース化を奨励する金銭的インセンティブ制度 |
| RMOSS | RoboMaster Open Source Software。ROS2ベースの標準ミドルウェア |
| rm_vision | 視覚認識フレームワーク。MITライセンス |
| 車輪脚 | ホイールレッグ。車輪と脚を組み合わせた移動機構 |
| 推薦研究生（保研） | 成績優秀者の大学院推薦入学制度 |
| ホワイトリスト | 全国普通高校大学生競技リスト。教育部が管理する学生コンテストの公式認定リスト |
| 共青団中央 | 中国共産主義青年団中央委員会 |
| 全国学連 | 中華全国学生連合会 |

## B. データソースの注意

本レポートで使用する主要な数値について、以下の注意事項を記す。

| 数値 | 確認された値 | ソース | 注意事項 |
|:---|:---:|:---|:---|
| 累計参加学生数 | 近20万名 | 人民日報2026年8月報道[1] | 2013年〜2026年の累計。2024年までの内部資料では「近10万名」とされていたが、2026年の最新報道では「近20万名」に更新された |
| DJI累計採用者数 | 近1,000名 | 央広網2026年5月報道[2] | 「超1,000名」とする表現もあるが、最新のメディア報道では「近1,000名」が標準的 |
| スタートアップ創出数 | 定義が不明確 | DJI内部資料（2024年） | 「RoboMaster関連」スタートアップの定義（参加者創業か、DJI出身者創業か）が資料内で統一されていない。100〜200社の範囲で様々な数値が報じられている |
| DJI累計投資額 | 累計3.5億元（推定） | 全天候科技2018年報道[3] | 2019年時点の累計推定値。大会運営費・人件費・施設費等を含む。物資割引のみで5,394万元という別の数値も存在する |
| DJI教育支援累計 | 5,394万元 | DJI公式2026年[4] | チームへの物資購入割引の累計額のみ。総投資額ではない |
| 2026年決勝参加校数 | 32校 | 人民日報2026年8月報道[1] | 全国大会（RMUC）の決勝進出校数 |

## C. 執筆者情報

本レポートは、次世代ロボットエンジニア支援機構 Scramble（一般社団法人）が作成した調査研究資料である。
